## 🧠 Essential Algorithmic Patterns

- 👥 **Two Pointers:** Shrinking windows and array convergence.
- 🪟 **Sliding Window:** Optimal continuous subarray & substring tracking.
- 🗝️ **Hash Map / Set:** Constant time O(1) element lookup and memoization.
- 🎯 **Binary Search:** Order O(log N) reduction over sorted ranges.
- 🌐 **Graph Traversals (BFS/DFS):** Level-order and exhaustive state exploration.
- 💡 **Dynamic Programming:** Overlapping subproblem state transitions.
- ⚡ **Bit Manipulation:** XOR calculations, bit masking, and binary math.
